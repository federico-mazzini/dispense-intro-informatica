DOMANDE - INVIARE E CONDIVIDERE FILE

Gruppi A e B: numerazione originale delle verifiche formative.
Ogni domanda vale 1 punto. Livelli originali: 1-17 facili, 18-25 medie, 26-30 difficili.

GRUPPO A - 3 DOMANDE

8. Un file salvato esclusivamente sul disco interno di un computer è automaticamente accessibile da qualsiasi altro computer, senza trasferirlo.
A) Vero
B) Falso

19. Hai caricato correttamente un documento su un servizio cloud. Il tuo computer si rompe. Che cosa puoi fare?
A) Recuperarlo soltanto riparando il computer
B) Accedere al servizio cloud da un altro dispositivo con il tuo account
C) Non puoi più recuperare il documento
D) Recuperarlo soltanto se avevi collegato una chiavetta USB

29. Devi inviare una cartella da 34 MB. Dopo averla compressa, ottieni un file ZIP da 28 MB. Il servizio email accetta allegati di massimo 25 MB. Quale soluzione è corretta?
A) Allegare comunque lo ZIP, perché è compresso
B) Rinominare lo ZIP con estensione .pdf
C) Caricare lo ZIP su un servizio cloud e condividere un collegamento accessibile al destinatario
D) Estrarre lo ZIP per ridurne ulteriormente la dimensione

SOLUZIONI - GRUPPO A

8. B
19. B
29. C

GRUPPO B - 3 DOMANDE

8. Quale affermazione descrive correttamente il salvataggio nel cloud?
A) I file sono conservati su server remoti e possono essere raggiunti tramite un servizio online
B) I file sono sempre salvati soltanto sul disco del computer
C) I file non possono mai essere scaricati sul dispositivo
D) I file vengono automaticamente trasformati in archivi ZIP

19. Condividi con un compagno il collegamento a un documento salvato nel cloud. Quale affermazione è corretta?
A) Chiunque può aprire il documento, indipendentemente dai permessi
B) Il compagno può accedere al documento soltanto se i permessi di condivisione lo consentono
C) Il compagno deve necessariamente possedere una chiavetta USB
D) Il documento deve obbligatoriamente essere in formato PDF

29. Hai aggiornato tre file all'interno di una cartella che contiene anche alcune sottocartelle. Devi inviare tutto a un compagno, mantenendo l'organizzazione originale. Lo ZIP creato ieri non contiene gli aggiornamenti e supera il limite degli allegati email. Qual è la procedura più adatta?
A) Cambiare il nome dello ZIP e inviarlo
B) Inviare lo ZIP di ieri, perché i file modificati si aggiornano automaticamente
C) Convertire un solo documento in PDF e inviare quello
D) Creare un nuovo ZIP dalla cartella aggiornata, caricarlo nel cloud e condividere un collegamento accessibile

SOLUZIONI - GRUPPO B

8. A
19. B
29. D
